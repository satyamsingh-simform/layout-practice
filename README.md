# Layout Practice Project

This project folder contains the HTMl and CSS layout collection, made to practice the layout to have effective control over flexbox, grid, position etc.

### Main Folders
- **Concept/**:Theory of concept like Flexbox, Grid, position, selector specificity, pseudo class and elements etc.
- **Layout-1**:Basic layout with scrollable main section created using CSS different concept.
- **Layout-2**:Profile card given by mentor to practice, created using flex, position. 
- **Layout-3**:Basic layout to practice Grid concept.
  - `1index.html`: CSS Grid layout with header, footer, aside, content areas
  - `2index.html`: Chess layout practice using CSS Grid. 
  - `3index.html`: CSS Grid laayout with number of boxes.
- **Layout-4**: Basic layout to practice Grid concept.
  - `1index.html`: CSS Grid layout with header, footer, aside, content areas
  - `2index.html`: CSS Grid with header nav section aside footer. 
- **Layout-6**: Multiple profile card created using Flex.
- **Layout-7**: Vatsal Review-1 layout.
- **Layout-8**: Jenith Review-1 layout.
- **Layout-9**: Mine Review-1 layout.
- **Layout-10**:Krish Review-1 layout.
- **Layout-11**:Mantu Review-1 layout.
- **Layout-12**:Notus-nextjs-template given by mentor to practice.


Each folder contains:

- `index.html` (or `1index.html`, `2index.html`): The HTML structure
- `style.css`: The CSS styles for the layout


## Learning Objectives

This project helps practice:

- CSS Grid layouts
- Flexbox layouts
- Semantic HTML structure
- CSS positioning techniques
- Time management will creating layout.
